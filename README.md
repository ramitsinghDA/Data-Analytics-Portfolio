# 📊 Superstore Sales Dashboard | Tableau

## 📌 Project Overview
This project is an interactive Tableau dashboard built using the Superstore dataset. It helps analyze sales performance, profit margin, return rate, product categories, and regional sales trends.

## 🎯 Objectives
- Analyze sales across different product categories.
- Track profit margin and return rate.
- Identify top-performing products.
- Visualize sales trends over time.
- Compare sales across different states and customer segments.

## 🛠 Tools Used
- Tableau

## 📈 Dashboard Highlights
- Sales KPI
- Profit Margin KPI
- Return Rate KPI
- Sales by Category
- Sales by Sub-Category
- Sales by State (Map)
- Sales by Segment
- Monthly Sales Trend
- Top 5 Products by Sales
- Interactive Filters
